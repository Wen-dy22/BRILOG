# BRILOG — Logística Eficiente

Sitio web institucional de **Brilog**, empresa de logística integral con cobertura marítima, terrestre y gestión aduanera para Argentina y el mundo.

---

## 🚛 Sobre el proyecto

Landing page moderna y responsive diseñada para presentar los servicios de Brilog de manera clara, profesional y orientada a la conversión. Desarrollada en HTML, CSS y JavaScript puro, sin dependencias ni frameworks externos.

---

## 📦 Servicios que cubre

- **Logística Marítima** — Importación y exportación FCL/LCL, cargas peligrosas, coordinación con agentes globales
- **Transporte Terrestre** — Distribución nacional, última milla, seguimiento satelital
- **Gestión Aduanera** — Despacho ante AFIP/DGA, clasificación arancelaria, gestión ante organismos de control

## 📐 Diseño

- **Paleta:** Rojo corporativo `#CC1E1E` sobre fondos blancos y gris claro
- **Hero:** Fondo oscuro `#16161A` con detalle de grilla y glow rojo
- **Tipografía:** Barlow Condensed 900 para titulares — DM Sans 300/400/600 para cuerpo
- **Animaciones:** CSS `IntersectionObserver` con fade-up al hacer scroll
- **Responsive:** Adaptado para mobile, tablet y desktop
